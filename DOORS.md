# Doors

A door is something that can't be undone. The agents never go through one without asking you first. You decide what goes on this list. A starting list:

- Deleting any file.
- Sending anything outside this folder: email, chat, a post, an upload.
- Spending money, or signing up for anything.
- Running a command that changes something outside this folder.
- Pushing to a shared repository.
